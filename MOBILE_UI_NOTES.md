# Mobile UI Update

- Admin portal is now full-screen on small devices and uses stacked registration cards instead of horizontal tables.
- Registration, participant/event, and event-count tables are responsive card layouts on <=640px screens.
- Search and filters stack cleanly on mobile.
- Admin action buttons wrap instead of overflowing.
- QR scanner and camera preview scale to the viewport.
- Main navigation becomes horizontally scrollable on narrow screens.
- Form controls use a mobile-friendly 16px input font to avoid browser zooming on iOS.
- Desktop layout is preserved above the mobile breakpoint.
